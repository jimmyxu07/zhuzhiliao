# 🎋 竹知了在线玩

在线体验竹知了玩具！拉动发出哇哇声，挑战转速PK，分享你的成绩卡。

纯前端静态页面，无需后端，无需下载。

## 功能

- **竹知了模拟器**：按住屏幕上下滑动，发出哇哇声
- **4种声音模式**：哇哇/嘎嘎/嘟嘟/嗡嗡
- **转速PK**：挑战1秒内拉动次数，排行榜PK
- **成绩卡生成**：Canvas生成精美成绩卡，支持下载/分享

## 技术栈

- HTML5 + CSS3 + JavaScript (ES5+)
- Web Audio API (声音合成)
- Canvas (成绩卡生成)
- SVG (竹知了卡通动画)
- localStorage (最佳成绩存储)

## 部署

直接将文件部署到任意静态托管即可：

```bash
# GitHub Pages
# 将文件推送到 gh-pages 分支即可

# 或者任意静态服务器
cp -r . /var/www/html/
```

## 开发

本地直接打开 `index.html` 即可运行，无需构建工具。
